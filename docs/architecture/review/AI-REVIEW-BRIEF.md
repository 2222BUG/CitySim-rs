## 三、裁决口径（沿用主文档第 7 章）

每条 ADR 给出四选一：**采纳 / 有条件采纳 / 拒绝 / 延后**，并附理由与验证条件。注意：

1. **状态词表**：文档条文只有 Proposed / Accepted / Implemented / Verified / Deprecated 五态；"候选""默认""暂定"不是状态。
2. **证据纪律**：spikes/ 下原型与 docs/benchmarks/ 报告是实测证据；文档中标"待验证/待定"处**没有**证据，不要脑补。Spike 原型 ≠ 正式实现。
3. **联动组**：NEW-17 / NEW-20 / NEW-23 是同一决策组（寻路调度体系），三项语义一致性验证完成前建议不单独定案其中任何一项。
4. **已知决策缺口**（decision-log 债务表 25 条，裁决时可引用）：特别关注 #23（单 tick 原子 A* 预算饥饿：搜索规模 > 每 tick 预算时"中止-从头重试"可能永不完成——NEW-20 的 A/B/C 机制就是为此设计）。
5. **拒绝/延后是合法裁决**：主文档允许按 history/ 中提案原件逐条剥离回退。
