# 一、债务 #31 裁决记录
署名：DeepSeek-V4.1

裁决：A（首选）> B（次选）> D > C。 推荐 A，但 A 须与 B 的“衔接参数”思路合并落地：凹形分支扩展（A）解决模型形式根因，B 的 k_turn 作为平台衔接参数吸收辨识不确定性。

理由： V1 三集协议数据明确显示 q(k) 自 k≈20‰ 起即为凹形，不存在独立线性自由流段，A 组 (205,135) 偏线性预测 52%，确认集自由流区误差 190‰（判据 100‰）——这是模型形式的结构性失败，不是参数调优能补救的。继续维持平台型/三角型线性自由流假设（B 若严格按原意只“各自辨识”而不扩展分支形式）在凹形数据上同样无法降低自由流区误差，C（放弃 MFD）则放弃了一个已在饱和区 PASS（102‰/判据 250‰）且具有统计价值的工具，代价过高。D（延后）在根因已明确的情况下不是建设性处置。

验证条件 / 修改要求：

A 的凹形分支形式须在 ADR-NEW-25 决策 1 中正式定义，不得停留在“对数/幂律/二次凹”的括号候选状态。 当前 ADR-NEW-25 决策 1 仍以“单调饱和平台型（自由流斜率 + 平台）”为默认形式，三角分支仅在观测到下降支时启用。V1 已证明“自由流斜率”本身在凹形数据下不可辨识。转 Accepted 前须将决策 1 修订为“自由流段按凹形函数（指定具体函数族与参数个数）拟合，平台段/下降支沿用现有逻辑”，并同步更新 TriangleFit 的语义或新增 ConcaveFreeFlowFit 类型。

重跑三集协议（A/B/C）并按同一判据复测 3a，不得只重跑拟合集。 现有 V1 数据是“三角/平台拟合结果 vs 观测”的误差，A 的凹形扩展必须用同一套留出协议重新评估：拟合仅用 A 集，B 集用于边界推导披露，C 集作为最终判据集。复测后 3a 的自由流区误差须从 190‰ 降至判据 100‰ 以内（或任务书修订后的校准阈值）。

B 的 k_turn 衔接参数应作为 A 的组成部分保留，而非 A 与 B 二选一。 凹形自由流段与平台段之间存在过渡区，纯凹形拟合可能在 k_c 附近产生偏差。建议在 A 的修订方案中引入一个显式的衔接参数（k_turn 或等效量），其物理含义与辨识方式须在 ADR 中写明，避免 A 落地后过渡区误差成为新的不可解释残差。

demand_pressure_bp(k_c) 的 k_c 语义须随 #31 裁决同步复核。 ADR-NEW-26 定义 demand_pressure_bp 时使用 k_c 作为压力分母。V1 拟合的 k_c=7710‰（来自平台峰值位置），在凹形数据下这个“临界密度”是否仍是降级信号中合理的压力参考点，未见证据。若 A 的凹形拟合产生不同的 k_c 估计，demand_pressure_bp 的输入语义和量级将随之漂移。须在 #31 关闭前明确 k_c 在凹形模型下的取值来源，并在 ADR-NEW-26 中补充说明。

对代码级审查重点 1-4 的逐项意见：

1. fit_triangle 最大割线在凹形数据下的系统偏差：确认存在，且是当前 FAIL 的直接贡献项。 ADR-NEW-25 决策 1 规定“自由流斜率=相邻采样点最大割线斜率（零密度导数上界）”。在凹形 q(k) 曲线上，最大割线出现在最低密度区间（接近零密度），而观测点覆盖的密度范围（A 集最低 k=7‰）已偏离零密度较远，最大割线斜率会系统性地高估实际低密度区的平均斜率。V1 数据中 A 组 (76,67) 偏线性预测 12%、(205,135) 偏 52%，即这一偏差随密度升高而放大的表现。A 的凹形扩展须用凹函数对全部自由流段采样点做整体拟合替代“最大割线”口径，而不是在最大割线基础上打补丁。

2. evaluate_fit 三区边界统计合理性：边界定义须显式回写 ADR，否则复测口径不可审计。 V1 数据中 pilot B 的边界是“after seeing B”推导的，confirm C 才用“original 10/20/25% re-split”。这说明当前三区边界并不是从拟合集 A 独立预定义的，而是带有一部分后见信息。A 复测时须将三区边界的定义规则（例如“自由流区 = k < 0.5·k_c”“拥堵区 = k > 1.5·k_c”之类不依赖评估集观测的确定性规则）写入 ADR-NEW-25 3a 条文，使复测的判据集划分可预先声明，消除“边界随数据调”的审计疑点。

3. mfd3a.rs 三集协议泄漏检查：现有材料中未见证据，须在 A 落地时补做。 可访问的 benchmark 文本显示 A/B/C 三集密度档不重叠（A: 2/4/8/16/32/64/128/256；B: 3/6/12/24/48/96/192/384；C: 5/10/20/40/80/160/320/640），这是协议设计的正确起点。但代码层面是否存在跨集信息泄漏（例如 mfd3a.rs 在拟合阶段读取了 B/C 文件的任何字段、或三集共享了同一随机种子导致样本相关性）未见证据。任务书要求代码级审查，而本轮可访问材料不包含 mfd3a.rs 源码。A 复测前至少应有一家评审确认三集协议在代码路径上严格隔离，并将结论附入 #31 关闭记录。

4. demand_pressure_bp(k_c) 参数语义联动：k_c 的稳定性在凹形模型下未经验证，须作为 #31 关闭的伴随条件。 当前 demand_pressure_bp(k_c) 以 k_c 为压力分母，而 V1 的 k_c=7710‰ 是从“平台峰值位置”读取的。凹形自由流模型下，“临界密度”可能不再是平台起点，而是凹函数曲率变化点或平台衔接点，其数值可能与 7710‰ 显著不同。若 A 复测后 k_c 发生数量级偏移，demand_pressure_bp 的输出压力将系统性失真，直接影响 ADR-NEW-26 的降级信号。须在 A 的修订方案中同时给出 k_c 在凹形模型下的辨识方法，并在 ADR-NEW-26 中注明“k_c 语义以 #31 裁决后的凹形拟合为准”。

新增风险（如有）：

A 的凹形函数族选择缺乏先验依据。 任务书将“对数/幂律/二次凹”列为候选，但 V1 数据仅覆盖一个 40×40 点队列场景，未见证据表明哪种凹形函数族在该场景及其他潜在路网形态下具有跨场景稳定性。若 A 落地时选定的函数族在复测中勉强通过 100‰ 判据但余量很小，后续场景扩展可能再次 FAIL。建议在 A 的验证条件中要求报告拟合残差的最差点而非仅区域均值，以暴露函数族选择的脆弱性。

A 修复后 MFD 的权威性边界可能被无意松动。 ADR-NEW-25 决策 2 明确规定 MFD 是非权威派生统计，降级触发只依赖确定性工作量单位（ADR-NEW-14），MFD 信号若接入降级输入须另行 ADR。债务 #31 的处置容易被误读为“MFD 修好了，可以接降级了”。须在 #31 关闭记录中显式重申：#31 的关闭只意味着 MFD 作为统计展示的模型形式缺陷已被处置，不改变 ADR-NEW-25 决策 2 的权威性边界。 MFD→降级的任何实质接入仍须走 ADR-NEW-26 及更上层的另行裁决。

B 作为 A 的补充若被误解为“B 单独可行”，可能导致形式选择回退。 本裁决推荐 A 为主、B 的 k_turn 为辅，但 B 的原始描述（“自由流段/平台段各自辨识”）并不强制要求自由流段为凹形。若执行时只取 B 的两段式框架而不嵌入 A 的凹形分支，等于回到“线性自由流段”的老路。须在修改要求中明确：B 的 k_turn 衔接参数只有在自由流段已经采用凹形函数的前提下才有意义，不得以 B 的名义绕过 A 的形式扩展。

     - 真正的问题在**不可辨识**：v_free 的物理上界恰为 1000‰（`lib.rs:317-319` 注释：每车每 tick 至多一条边），而拟合返回值恰为 1000‰（`mfd-3a-reference.txt` 的 `v_free = 1000‰`）。数据无法区分"真斜率=1000"与"真斜率>1000 被截断"→ 该参数**不是由数据辨识出来的**，应报告为"≥ 曲线首段斜率，被物理上界夹住"。当前把硬编码上限当作拟合结果公布。
     - 稳健性：最大割线估计对**单点噪声敏感**（一个噪声段即可抬高估计值）→ v_free 变 → `k_turn = q_max·1000/v_free` 变 → 三区边界变 → 3a 的 PASS/FAIL 可能翻转。建议 v_free 改由**模型结构常量**给出（行程时间决定），或用稳健估计（中位斜率 / 最小二乘 + 残差检验）并报告区间。
     - 结论：重点 1 的问法在本数据上不是关键症结；关键症结是"单斜率 + 平台"两段结构无法表达斜率随 k 衰减的曲线（确认集 k=329‰ 误差 521‰），而这种衰减在本基准里来自**准入争用**而非交通物理 → 故修基准（条件 2）优先于换曲线形式（A/B）。
  2. **`evaluate_fit` 三区边界（k_turn/2、4·k_turn、2·k_turn）是否有统计合理性？** 不合理，至少四处硬伤：
     - ① **自指**：区域边界由被评估的拟合参数导出（`lib.rs:226-229, 239-245`），评估区域随被评估模型漂移；"4·k_turn"系试点集 B 导出（已在 methodology note 2 披露，披露本身正确），但 **k_turn/2 的选择无任何披露**，它恰是"自由流区画到哪里"的关键自由度。
     - ② **敏感到可翻转结论**（我的复核推算）：k_turn = 248·1000/1000 = 248；确认集自由流区取 k < k_turn/2 = 124‰ → 含 k=20/43/100 → 最大误差 190‰（FAIL）；取 k < k_turn/4 = 62‰ → 含 k=20/43 → 最大误差 48‰（**PASS**）。同一份数据、同一模型，仅改边界即由 FAIL 变 PASS → "190‰ FAIL"不宜作为 #31 的唯一量化依据；#31 应以中段结构偏差立据（A 组 (205,135) 偏 52%、确认集 (329,163) 偏 521‰）。
     - ③ **失效区恰好无判据**：确认集只有 1 个点（k=329‰）落在转折区，而它恰是全表最大误差（521‰）；协议把模型失效最严重的区划为"只记录"，使"饱和 102‰ PASS + 自由流 FAIL"的组合在观感上掩盖"转折区错 3~5 倍"。
     - ④ 顺带修正：`evaluate_fit` 的 rustdoc（`lib.rs:198-201`）写 2·k_turn，实现与输出用 4·k_turn（修改要求 7）。
     - 建议：区域边界固定为绝对密度区间（如 k<64‰ / 64≤k<512‰ / k≥512‰，与拟合无关），或以曲率拐点的实测估计为准；每次复测附**边界敏感性表**（k_turn/2、/4、/8 三种取法下的结论）。
  3. **`mfd3a.rs` 三集协议的 seed 派生与窗口均值口径是否可复现、有无泄漏？**

     - **泄漏**：数据层面**无泄漏**（拟合只用 A；B 明示 pilot；C 为裁决集且密度点与 A/B 互不相同）。但有两类"口径泄漏"须披露：① 判据与模型形式是在看过 A（及 B）之后确定的（原 10/20/25 单切判据被重划为三区，methodology note 1-2），故 C 只对"已定形状"独立，不对"判据本身"独立；② 种子族共用（A/B/C 同用 SEED..SEED+7），确认集不是种子意义上的留出。

  4. **`demand_pressure_bp(k_c)` 的 k_c 取自拟合值——若 #31 改模型形式，该接口参数语义是否需要同步改？** 需要，而且问题比"同步改"更根本：
     - 在平台型（本数据实际类型，`descending_branch_observed=false`）下**不存在临界密度**，实现里的 `k_c_permille` 实为"拟合集 A 中 q 最大点的密度"= 拟合阶梯**右端点**（本次 7710‰）。于是压力语义 = "当前密度 ÷ 最大采样密度"，与基准阶梯设计强耦合：改一下 A 的密度阶梯就会改变权威降级的触发门限 → 跨版本语义漂移，正是 ADR-NEW-25 决策 2"MFD 参数误差不得放大进权威状态"要防的事（ADR-26 用"L1 封顶"限制了影响面，但 L1 仍是权威状态变更，入档入摘要）。
     - `k_c == 0` 返回 10000（满压力）→ 把"参数未知/不可辨识"映射成"最高压力"（`lib.rs:136-138`），方向与安全默认相反。
     - 分子分母不同源：`demand_pressure_bp` 用本实例**瞬时** k（`lib.rs:139`），k_c 却来自另一套（8 seed 平均）拟合口径。
     - 结论：在 #31 未解决、k_c 不可辨识前，该接口**不应进入权威降级路径**；若保留，须改为分母有独立语义、未知值 fail-safe 为 0，并把版本稳定性写入 ADR。
