# 评审流程常驻规矩（REVIEW-CONVENTIONS）

维护者约定（2026-11-19 起生效），适用于此后每一轮评审分享（ADR 裁决、阶段收口、专题评审）。

## 1. 分享链接给全

每份分享文案必须同时包含：

1. **仓库链接**：https://github.com/2222BUG/CitySim-rs
2. **RAW 链接**：被评审文件逐个给出（raw.githubusercontent.com 精确路径，中文文件名 URL 编码）——不得只给仓库首页（对方可能无法拼接路径）。
3. **ZIP 下载链接**：材料包直链 + 全量仓库 ZIP
   （离线 AI 可用附件形式转发材料包 zip）。
4. **最新版 ZIP 文件随文案发到**（2026-11-19 追加，维护者要求）：每次发分享链接，
   必须同时把**当前最新版材料包 ZIP 文件**发给接收方（附件直接发，或给出可下载的
   直链）——不得只发链接不发包。ZIP 必须基于当前最新提交重新打包（旧包不复用），
   并在 MANIFEST 中标注打包时的 commit hash。

## 2. 报告者署名

要求每位报告者在报告中注明：**真实名字 / GitHub 昵称 / AI 模型型号（三选一，可并列）**。
AI 署名**推荐**到具体型号/版本（如 DeepSeek-V4.1flash、qwen4-max、MiniMax-M3.1-Flash、
GPT-6）——便于质量记录与冲突排查；泛称（"某 AI"“大模型"等）**同样计票**（2026-11-19
负责人裁定：署名要求为推荐性质，不强制具体型号）。完全未署名的报告不计入裁决统计，只作参考意见。

## 3. 每轮至少一家代码级审查

（2026-11-19 追加，起因：ADR-NEW-24 第二轮评审八家中仅 QWEN4-MAX 做了代码级审查，
发现两条真实契约缺陷——溢出环绕违反 ADR-NEW-21、父边回溯取 min edge id；
其余七家均为条款级审查，未能发现。）

- 分享文案中明确要求：**请至少安排一位评审人做代码级审查**（通读被评审模块源码与测试，
  不只看条款文本）；或在任务书中指定某位评审人承担代码级审查。
- 代码级审查的发现必须给出**文件+行号级证据**（如 `lib.rs:182 wrapping_add`），
  未给出处的代码缺陷主张按"未见证据"处理。
- 代码级审查重点：实现与 ADR 条文的逐条对应、数值契约（溢出/舍入/边界）、
  测试是否覆盖声称的不变量、数据口径（分母/计数器语义）。
- 裁决汇总时，代码级审查发现的缺陷单独列出并要求工程侧修复+回归测试后回贴。

## 4. 裁决格式与回传

- 四选一：采纳 / 有条件采纳 / 拒绝 / 延后（拒绝和延后是合法裁决）。
- 引用条文编号与文件行号支撑每个判断；材料未覆盖的点标"未见证据"。
- 回传渠道：issue 或直接交维护者转贴；裁决原文归档 `docs/architecture/review/archive/`。

## 5. 分享文案标准版式（2026-11-20 追加，维护者要求）

以后每份分享文案（投票邀请/审计邀请/评审邀请）**都按此版式**，可直接整段复制群发：

1. **抬头**：【类型】项目名 · 对象（预计耗时）；一句话背景+一句使命（含"推翻判定是
   合法结论"类开放性声明）。
2. **① 任务书**：raw 链接（先读）。
3. **② 材料包多通道**（标注"同源同基准，读哪个都行"，按可靠性排序）：
   - A. 附件直传（推荐）——ZIP 文件本消息挂附件；
   - B. 单文本包 raw 链接（ZIP 通道失败时的文本保底，全部材料文件全文拼接单一 MD，
     与 ZIP 同基准逐字节同源，入仓 docs/architecture/review/*-BUNDLE.md）；
   - C. Release 下载页（Assets）；
   - 备用镜像（jsDelivr）+ 全量仓库 ZIP。
   每次发分享必须重新打包（旧包不复用），MANIFEST 标注 commit hash。
4. **③ 范围清单**：编号逐项，最重要的排第一并加粗。
5. **④ 回传格式**：指向任务书对应节（裁决格式含逐项一行+总体一行）。
6. **⑤ 约定**：署名（推荐具体 AI 型号/版本，泛称同样计票，完全未署名不计票）、
   至少一家代码级审查附行号证据、证据纪律（未覆盖标"未见证据"）、
   **不通过/要求重做是合法结论**、回传渠道 issue 链接。
7. 文案末尾附维护者后续动作一句（"结果回来我做工程侧核对→按裁决入账或返工"）。

范例：2026-11-20 债务闭合审计邀请文案（issue #27 轮）。
