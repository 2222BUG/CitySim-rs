# ADR-NEW-25：MFD 交通模型与验证方案

- 编号：ADR-NEW-25（暂定，入仓正式重编号时保留映射）
- 状态：Proposed（草案，待第 7 章评审流程正式裁决）
- 日期：2026-11-19
- 关联主文档章节：2.6（交通流量模型）、2.1（MFD 行）、Stage 2C（MFD 模型验证、交通模型可复现验证场景）
- 来源：Stage 2C 实施（C1）；设计审计"验证只有一句话无场景无指标"处置
- 裁决人：项目负责人（可委托外部评审，遵循 review/REVIEW-CONVENTIONS.md）

## 背景

主文档将 MFD（Macroscopic Fundamental Diagram，宏观基本图）列为交通流量模拟候选模型
（2.6："交通流量模型以 MFD 为候选设计方向。MFD 的适用范围、参数校准、与微观 Agent
交通行为之间的耦合方式，需要通过独立测试确认"），但全文没有验证场景、指标与判据。
设计审计与外部评审均指出：无场景无指标的"待验证"无法执行。本 ADR 给出验证方案本身
（模型形式仍为候选，参数仍待校准）。

## 问题

1. MFD 曲线形式未定（三角基本图 vs 二次凹曲线 vs 分段拟合）。
2. "适用范围、参数校准、耦合方式"三项要求（2.6）无验证场景与判据。
3. MFD 输出是否反馈权威模拟（影响路径选择/降级）未定——反馈则必须满足 2.9 确定性边界。
4. 交通模型本身（sim-traffic）无任何实现，"交通模型具备可复现验证场景"（Stage 2C 退出条件）
   无从谈起。

## 决策

1. **模型形式（候选，校准后定案）**：区域级基本图 q(k) 采用**分段线性三角基本图**为基线
   （自由流分支斜率 v_free、临界密度 k_c、拥堵分支斜率 −w），二次凹曲线为备选。
   参数（v_free、k_c、q_max、w）不得拍脑袋写死，必须由决策 3 的校准流程从微观基准采样得出。
2. **MFD 的权威性边界**：MFD 输出**默认只作宏观统计与降级/背压输入（非权威侧消费）**，
   不直接反馈权威路径选择。若将来反馈，必须以确定性定点形式（SimScalar/整数）并另行 ADR
   修订。理由：反馈回路会把 MFD 参数误差放大进权威状态，且 2.6 明令"不得在缺少验证的情况
   下将 MFD 的理论表现直接当作实际引擎性能"。
3. **三项独立验证**（2.6 原文要求，逐项给场景+指标+判据）：
   - 3a 适用范围：微观基准（本 ADR 决策 4 的可复现场景）下扫描注入密度阶梯，比较
     MFD 聚合 (k, q) 与微观实测 (k, q)——判据=自由流区相对误差 ≤10%、临界密度位置
     偏差 ≤20%、拥堵区误差 ≤25%（阈值为占位候选，校准后复核）。
   - 3b 参数校准：q_max/k_c/v_free/w 由微观基准最小二乘（定点实现）拟合产生，
     拟合输入输出全部落 docs/benchmarks/；同种子重校准必须逐位一致（确定性约束）。
   - 3c 耦合方式：MFD→降级/背压输入路径（如区域密度超 k_c 则触发 L1 降级信号）须经
     "注入延迟/线程数变化不改变摘要"验证（Stage 2C 退出条件第 5 条）。
4. **可复现验证场景（交通基准场景 T-Bench-1）**：40×40 双向网格路网、固定种子
   0xTBD（沿用 2.10 参考场景口径）、OD 对由 sim-rng event_u64 派生、车辆注入按密度
   阶梯 0.05 步长从 0 到过饱和、每档稳定 200 tick 后采样 (k, q)、上升/下降双向扫描
   （检测滞回）。场景全部参数进 fixture（sim-test-support 口径），逐 tick 折叠 GlobalDigest。
5. **确定性判据**：同种子两跑逐点 (k, q) 序列一致（GlobalDigest 相等）；
   密度阶梯注入顺序无关性（同一总注入量不同顺序→终态摘要一致，允许车辆计数差异归并）。

## 考虑过的替代方案

| 备选 | 处置 | 理由 |
| --- | --- | --- |
| 二次凹曲线 q(k) | 备选 | 拟合自由度高但外推危险；三角基线更保守 |
| MFD 反馈路径选择 | 否决（默认） | 参数误差放大进权威状态；2.6 验证前禁止 |
| 纯统计不建模 | 否决 | 无法支撑降级输入与"交通流量模拟"定位 |
| 直接采用 CS 系列交通口径 | 否决 | 无公开数据可复现；T-Bench-1 自建基准 |

## 影响

- sim-traffic（当前空骨架）获得最小实现范围：微观基准（车辆沿最短路行驶+路段容量排队）
  +区域聚合采样器+基本图拟合（定点）。
- EC-01/EC-04：降级信号增加"区域密度"输入源（须走确定性工作量单位口径，见 ADR-NEW-14）。
- 债务 #6（坐标/单位/角度）部分收窄：密度单位=辆/格（网格路网），流量单位=辆/tick。

## 验证方法

1. T-Bench-1 场景实现并通过确定性判据（决策 5）。
2. 3a/3b/3c 三项各自产出指标文件入 docs/benchmarks/mfd-*.txt。
3. 全部阈值经校准后复核并回填本 ADR（占位值不得直接转 Accepted）。
