## 背景

Stage 2A 实施前有四个未决问题会直接破坏确定性承诺：

1. CSR 定案表述自相矛盾（2.1 标 Accepted、2.5 说"待性能测试"、第 7 章列为未决问题）；
2. A* 的平局打破、邻居展开序、启发式定点舍入全部空白——同一张图同一对起终点，实现者可能合法地长出两条不同路径，GlobalDigest 立即分叉；
3. Stage 2A 退出条件"路径搜索结果符合预期"没有可测判据；
4. EC-01 事务取消语义与冲突合并未定义（债务 #18）。

## 决策

### 1. CSR 路网定案（债务 #8）

路网静态拓扑采用 CSR（Compressed Sparse Row）：

- `offsets: Vec<u32>`（节点 n 的邻接区间 = offsets[n]..offsets[n+1]）+ `edge_ids: Vec<u64>`，邻接条目按 **(node_id, edge_id) 升序**（数组序即确定性迭代序）；
- 动态代价独立数组 `costs: Vec<i64>` 按边 ID 索引（2.6 区分拓扑与代价）；
- **拓扑事务 = 整表重建 + 原子替换**（版本号 +1）；**代价事务 = 原位写入**（版本号 +1，影响区域由 ADR-NEW-23 细则约束）；
- 性能测试不再是定案前置——改为实施后实测记录入 docs/benchmarks/（推翻"待性能测试再定案"，理由：查询 O(度)、迭代序天然确定，唯一候选中风险最低）。

### 2. 确定性 A* 细则（债务 #17/#26 核心）

同一 `(图, 起点, 终点, 代价数组)` 必须唯一决定输出路径：

1. **启发式**：h(n) = 曼哈顿距离（网格 1 mm 整数坐标），i64 计算、乘法 i128 中间值（2.4），舍入"就近，0.5 远离零"；h 可采纳（h ≤ 真实代价，前提=边代价下限 ≥ 1 mm 等价长度；若边代价可更小，h 按比例缩小，保持可采纳）；
2. **open 集排序键 = (f, h, node_id) 全序升序**——f 相同比 h，再比 node_id 升序，平局打破完全确定；
3. **邻居展开序 = CSR 数组序**（即 (node_id, edge_id) 稳定序）；
4. **closed 判定**：节点首次展开即闭合；仅当 g 严格更小时允许 reopen，reopen 按同一排序键入队；
5. 实现必须用确定性数据结构（排序 Vec/二叉堆外的有序结构），禁 BinaryHeap 作 open 集（相等元素顺序未定义）。实现替代名录：有序 Vec / 稳定二叉堆 / BTreeMap——须显式给出确定性顺序，不得依赖隐式行为；
6. **溢出契约**（继承 ADR-NEW-21 决策 3）：g/f 累加与 h 计算禁止静默环绕，h 用 i128 中间值饱和收敛、g/f 用 saturating_add；溢出处理确定性（饱和到 i64::MAX，不引入环绕负值）——已实施，回归 overflow_saturates_deterministically；
7. **父边记录**：回溯必须使用松弛时实际采用的边 ID（parent 记 (父节点, 边 ID)），禁止按"最小 edge id"反推——平行同向边不同代价时反推会使返回边集与报告 cost 不一致并污染过期窄判边集——已实施，回归 parallel_edge_reconstruction_is_exact；
8. **前驱裁决与 L=|V| 上界**：g 相等不松弛（仅严格更小才更新），等价于"保留先发现前驱"（明文）；前提=h 一致性 h(u) ≤ cost(u,v) + h(v)（由边代价下限不变量保障，动态代价更新后仍须成立）；一致性成立时每节点至多弹出一次、L=|V| 与 reopen 不冲突；未来引入非一致启发式须重证上界或改免 reopen 口径（债务 #30）；
9. **每 tick 从头原子搜索**：搜索不跨 tick 保留任何中间状态（open/closed/g/parent 全部丢弃），与"存档点仅 tick 边界"共同保证强读档等价。

### 3. 机制 B 参数口径（ADR-NEW-20 三硬约束细化，G2 承载）

- 放大幅 **g = 2**；每 tick 节点预算 b 为系统参数（入 2.7 预算声明，阈值实测回填属 ADR-NEW-14 待决）；
- 上限 **L = |V|**（单请求展开节点数不可能超过节点总数）；
- 递增函数 **B_k = min(b·2^k, L)**，k = 连续让步次数 budget_yield_count；
- 解析上界（ADR-NEW-20 三硬约束）：k ≤ ⌈log₂(|V|/b)⌉ + 1 个 tick 内要么完成要么进入受阻判定；最坏累计**总展开** ≤ |V|·g/(g−1) = 2|V|（2026-11-19 措辞修订：其中浪费 < |V|，有功展开 ≤ |V|）；
- 递增属工作量驱动确定性规则，**不触发** ADR-NEW-14 条 4 的配置变更记录（区别于人工调参）；
- **定案（债务 #29，2026-11-19 Stage 2B 前置定案）**：全局每 tick 寻路配额——每 tick 创建全局预算 `TickBudget{remaining = Q}`（确定性工作量单位=节点展开数，对齐 ADR-NEW-14 条 3），逐请求上限 B_k ≤ min(b·2^k, L, remaining)，请求实耗展开数扣减 remaining；remaining 耗尽即其余请求让步（budget_yield_count+1），多请求处理顺序=请求 ID 稳定序；每 tick 预算独立重置（Q 重置归满，k 递增体现等待）。**效果**：全局每 tick 总展开 ≤ Q（化解 Claude 指出的"单 tick 最坏展开=|V| 与 ADR-14 条 3 冲突"），单请求仍受 min(b·2^k, L)。Q=65536 **已定案**（2026-11-19 决策3 投票 1a，9:1 通过；含义=对实测 worst 398@40k 留余量的保险丝；单一来源 `sim-pathfinding::TICK_QUOTA`，2026-11-20 X5 钉死消除多处字面量互斥）。让步计数（budget_yield_count）为模拟状态而非配置，入存档（EC-03）与摘要（G3 已实装）。

### 4. Stage 2A 退出判据（债务 #17/#18 收口）

| 判据 | 口径 | 阈值 |
| --- | --- | --- |
| 最优性 | 确定性 A* 输出代价 == Dijkstra 参考实现代价 | 测试断言（非抽样） |
| 唯一性 | 同输入重复运行（含乱序注入）路径逐边一致 | 测试断言 |
| 重算率 | 固定场景过期重算**请求**占比（分母=请求总数；2026-11-19 第二轮评审统一口径。实测 3/200 = 0.015 PASS；G5 报告 0.0027 = 3/1100 系 stale 检查口径，保留标注） | ≤ 5% |
| 阻塞率 | MarkBlocked 终态占比 | ≤ 1%（实测 0.00，PASS） |
| 预算上界 | 任一请求完成 tick 数 | ≤ ⌈log₂(|V|/b)⌉+1（解析断言；实测 4 ≤ 11） |

**取消语义**：取消 = 从队列移除；请求 ID 不复用；路网版本不变；已进入搜索的请求按"中止不发布"处理（ADR-NEW-20）。
**冲突合并**：路网事务按 tx_id 全序串行发布；影响区域重叠的并发事务**不合并**，后者拒绝并入队重试（确定性：拒绝按 tx_id 序判定）。重试事务的 tx_id 语义**定案（债务 #28，2026-11-19 Stage 2B 前置定案）**：**沿用原 tx_id，按 tx_id 全序重排入队重试**（事务身份稳定=2.8 稳定键原则；"新 ID 显式链接"需额外映射状态入档入摘要，复杂化存档最小集，否决）；重试上限=3 次（与 recompute_limit 默认同口径），超限事务进入受阻状态等待显式处理并产生诊断事件（衔接受阻状态语义）。
**切换阈值过渡口径（债务 #27；2026-11-19 V4 多场景基线实测回填）**：机制 B→A 切换
阈值实测基线已入 docs/benchmarks/G5-threshold-baseline.txt（200×200 网格、每场景 200
请求、机制 B b=64 g=2 L=|V|）：

| 场景 | dup mean/p95/max | worst 单次尝试展开 | worst 让步次数 | worst 请求墙钟 |
| --- | --- | --- | --- | --- |
| open | 0.404 / 0.598 / 0.635 | 353 | 3 | 0.67 ms |
| obstacle-20% | 0.523 / 0.648 / 0.664 | 10,228 | 8 | 21.8 ms |
| maze-corridor | 0.471 / 0.641 / 0.662 | 17,047 | 9 | 36.0 ms |

结论：
1. **dup_rate 被证伪为切换判据**——三场景 max 均 ≤0.664，与解析上界 (2^k−1)/(3·2^{k−1})
   → 2/3 吻合；任何 >0.7 的 dup 阈值（含 Grok 1.0/1.5）结构性不可达，0.65 级阈值
   （Gemini P95）会误触发 open 基线。dup_rate 仅作遥测记录。
2. **候选切换判据改用确定性工作量单位**（对齐 ADR-NEW-14 条 1，墙钟只做遥测）：
   单次尝试展开数 > 4096（open 353 不触发；obstacle/maze 10k~17k 触发）**或**
   单请求让步次数 ≥ 8（open worst 3 不触发；obstacle/maze 8~9 触发）→ 切机制 A
   （增量续算）。
3. 状态：**候选提案（Proposed）**，数值随 G2 一并定案；墙钟 SLO 换算（如 MiMo
   1 ms 档）须以实测 ns/展开标定后并入遥测告警，不作确定性触发。

### 5. 考虑过的替代方案

- BinaryHeap 作 open 集：**否决**——相等元素顺序未定义，破坏唯一性；
- Dijkstra 全量搜索：**否决**——无法按机制 B 分段让步；
- 浮点启发式：**否决**——违反 2.9 条 3；
- 动态拓扑原位增量更新（而非整表重建）：**暂缓**——200×200 压测若显示重建成本过高（G5 数据），按修订流程切换（与机制 B 的"数据推翻默认"同条款）。
