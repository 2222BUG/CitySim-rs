# ADR-NEW-23：路网事务过期结果细则与行走删路行为（Spike C 实测定案建议）

- 编号：ADR-NEW-23（暂定编号，正式进入仓库后重编号并保留映射）
- 状态：Proposed（待评审裁决）
- 日期：2026-11-18
- 关联主文档章节：3.1 EC-01（过期结果策略块）、2.5、2.6、4.2 EC-07；ADR-NEW-17（本 ADR 是其待决事项的取数来源）、ADR-NEW-20（单 tick 原子搜索口径）
- 来源：Spike C（`spikes/network-tx-spike/`，8 测试全过，2026-11-18）；证据报告 `docs/benchmarks/Spike-C-NetworkTx-REPORT.md`

## 背景

ADR-NEW-17 列出的待决事项——影响区域表示法、相交粒度、重算上限、兜底三选一、行走中道路被删除行为——
按主文档要求由 Spike C 的数据确定。Spike C 原型已实现完整发布/查询/过期判定管线并验证六项主文档验证目标。

## 问题

ADR-NEW-17 的策略框架（影响区域相交判断）已定为默认候选，但缺以下细则无法进入实现：

1. 影响区域用什么数据结构、相交判断的粒度是什么；
2. 重算上限取多少、超限后走哪个兜底；
3. 行走中道路被删除时三种候选（停止/回退/就近重算）如何取舍。

## 决策

1. **影响区域表示**：轴对齐包围盒 `Region { min_x, min_y, max_x, max_y }`（i64，网格单位 1 mm，
   对齐 2.10 最小空间分辨率）。拓扑修改（增/删边）与动态代价更新**都必须声明影响区域**（ADR-NEW-17 条文 8）。
   判断保守相交：宁可多重算，不误接受。
2. **相交粒度（聚合规则，条文 7）**：base 与 current 版本之间全部已发布事务的影响区域**并集**，
   与结果路径的几何区域（路径各边包围盒并集）求交；命中 → 重入队。
3. **重算上限**：每请求 `recompute_limit = 3`；超过上限进入兜底（条文 10 前向进展不变量：
   每个 Agent 在有限 tick 内获得可用路径或进入明确定义的受阻状态）。
4. **兜底默认 = 标记受阻（MarkBlocked）**：唯一无歧义终态。局部可行路径（PartialPath）与沿用旧路径有效段
   （UseValidPrefix）保留为增强候选（枚举预留），启用前须先定义"部分路径的可接受性"（关联债务 #18）。
5. **行走中道路被删除**：**RerouteNearest（就近重算）优先**，重算不可达或超限 → 进兜底；
   **Stop（原地停止）为安全保底**（永远合法、零开销，供预算耗尽时使用）；Backtrack（回退）不推荐
   （长路径退化代价大且不前进），保留枚举供特殊场景。
6. **处理顺序**：过期结果按请求 ID 稳定排序处理（2.9 条 4），不依赖到达先后。
7. 合法性（条文 9）与相交判断**解耦**：路径所经边在当前路网不存在 → 必重入队，与影响区域判断无关。

## 考虑过的替代方案

- 影响区域精确几何（线段/多边形）：相交更准但求交成本随路径长增长（ADR-NEW-17 已记）；包围盒保守相交在
  修路热点场景会多重算，可接受。
- 重算上限 = 1（最快进兜底）：实测持续修路下过早放弃；=3 在 `forward_progress_under_churn` 下 10 tick 内
  必达终态，取 3。
- 兜底 = PartialPath：需要定义"部分路径可接受性"语义（到达不了目的地算什么状态），债务 #18 未清前不启用。
- 行走删路 = Backtrack：永远合法但不前进，与前向进展不变量精神相悖。

## 影响

- EC-01 过期结果策略块获得全部实现细则（状态仍随 ADR-NEW-17 裁决推进）；
- EC-07 属性测试"重算次数不超过上限"有了具体上限（3）；
- 与 ADR-NEW-20 衔接：单 tick 原子搜索下"重做展开消耗预算"问题不存在，本 ADR 的重算上限只管
  "跨 tick 的重复重入队"；
- 路网数据结构（Edge/Region）为最小可行版，正式数据字典仍属债务 #8。

## 验证方法

- `spikes/network-tx-spike/` 8 测试：`stale_aggregation_rule`（聚合规则）、`stale_legality_check`（合法性解耦）、
  `forward_progress_under_churn`（前向进展 + 重算上限）、`walk_policy_comparison`（三方案比选）、
  `interleaved_publish_query_threads`（并发不变量）；
- EC-07 属性测试：重算次数 ≤ recompute_limit，注入任意事务序列断言前向进展；
- EC-11 R2 强读档等价测试（含在途寻路请求，依赖 ADR-NEW-20 口径）；
- 大规模发布/查询吞吐归 Stage 2A 基准（docs/benchmarks/）。
